🧪 Pace Settings Loading Test

This test will verify that pace and heart rate settings are properly loaded from saved routes.

Test Instructions

  1. Make sure the development server is running at http://localhost:3000
  2. Make sure you have at least one saved route with pace settings in the database
  3. Click "Run Test" to simulate the loading process

Test Steps

Step 1: Check if development server is accessible
Step 2: Test authentication (if required)
Step 3: Load saved routes page
Step 4: Check if routes with pace settings exist
Step 5: Simulate loading a route with pace settings
Step 6: Verify sessionStorage contains correct pace settings
